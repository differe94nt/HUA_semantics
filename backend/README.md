# 把學生答案存到 Google 試算表、截圖存到雲端硬碟

線上版（claude.ai Artifact）本來就有共用資料庫，**不需要**做這一節。
只有當你想用「本機 HTML 檔」或「GitHub Pages」上課、又希望各組答案自動收到你的 Google 帳號時，才需要設定。

設定一次約 5 分鐘：

1. 到 [Google 試算表](https://sheets.new) 開一個新的空白試算表，命名例如「偏誤句小組任務」。
2. 選單 **擴充功能 → Apps Script**，把編輯器裡原本的內容全部刪掉，貼上 `backend/google_sheets.gs` 的全部內容，按儲存。
3. 右上 **部署 → 新增部署作業**：
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**（學生不用登入 Google 就能存答案）
   - 按「部署」，第一次會要你授權；完成後複製 **網頁應用程式網址**（`https://script.google.com/macros/s/…/exec`）。
4. 打開 `content/config.js`，把網址填進 `sheetEndpoint`，然後執行 `python3 build.py`。
5. 用瀏覽器打開 `dist/student_tasks.html`，首頁應顯示「已連線 Google 試算表」。隨便選一組按一次儲存，試算表裡會出現 `groups` 工作表和那一列。

之後每次修改 `.gs` 檔都要 **部署 → 管理部署作業 → 編輯 → 版本：新版本** 才會生效。網址不會變。

## 更新程式碼（例如加上截圖上傳之後）

1. 在 Apps Script 編輯器打開「程式碼.gs」，全選刪除，貼上新的 `backend/google_sheets.gs` 全部內容，儲存。
   - 在終端機執行 `pbcopy < backend/google_sheets.gs` 可以直接複製到剪貼簿。
2. **部署 → 管理部署作業 → 鉛筆 → 版本：新版本 → 部署**。
3. 因為新程式要存檔到雲端硬碟，Google 會請你重新授權；看到「Google 尚未驗證這個應用程式」時，按「進階 → 前往（專案名稱）」。
4. 舊的 `groups` 工作表會在下一次讀取時自動換成新欄位，原有資料會保留。

## 資料長什麼樣子

- `groups` 工作表：每組一列。前面是可直接閱讀的欄位（和教師端匯出的 CSV 相同），最後一欄 `json` 是完整原始資料。
- `settings` 工作表：教師按「通知全班目前階段」時寫入。
- `uploads` 工作表：每張截圖一列（組別、雲端硬碟檔案 ID、網址、上傳時間、是否已移除）。
- 截圖檔案：存在試算表所在資料夾裡的「偏誤句小組任務_截圖」，檔名開頭是組別，例如 `g4_20261017-101500_我的網頁.jpg`。學生按「移除」時，檔案會被丟到垃圾桶，30 天內可以救回。
- 很長的文字（例如 AI 回答裡的整份程式碼）超過一格的上限時，`json` 會接著寫到右邊幾格；可讀欄位只保留前 45,000 字，完整內容在 `json`。

試算表本身就是備份；也可以用 `tools/export.py --from-sheet <網址>` 把資料抓回 `data/exports/`。

## 注意

- 網址是「所有人可存取」，知道網址的人都能寫入；網址只放在 config 裡、不要公開張貼。課後可以把部署封存。
- Apps Script 免費額度足夠一個班級使用（每天數萬次請求）。學生端每 8 秒只抓自己那一組，教師端才抓全班。
- 截圖預設設成「知道連結的人可以檢視」，教師端和組員才看得到縮圖。檔案 ID 很難猜，但連結被轉傳出去就看得到。想要只有自己看得到，把 `.gs` 開頭的 `SHARE_UPLOADS_WITH_LINK` 改成 `false`；學校帳號若禁止對外分享，也會自動維持私人。
